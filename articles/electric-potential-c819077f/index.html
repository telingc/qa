For Non-static Fields

To avoid any possible ambiguity, I should perhaps put a prime on the integration variable:

V(r)=−∫OrE(r′)⋅d l′V(\mathbf{r})=-\displaystyle\int_{\mathcal{O}}^{\mathbf{r}}\mathbf{E}(\mathbf{r'})\cdot d\, \mathbf{l}'V(r)=−∫Or​E(r′)⋅dl′

  1. r\mathbf rr : The coordination of the end point.
  2. r′\mathbf r'r′ : Coordination of the current point on the integration route.
  3. l′\mathbf l'l′ : The differentiated displacement vector. Notice that the line integral of electrostatic field is path independent, it's recommended to find the most trivial integration path.

The Standard Reference Point

The standard reference point of electrostatics is a point infinitely far from the charge. But if the charge distribution it self extends to infinite, this convention fails.
